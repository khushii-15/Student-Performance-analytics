# 📊 Student Performance Analytics System

## 📌 Overview

Student Performance Analytics System is a beginner-friendly data analytics project developed using Python.

This project analyzes a sample dataset of students to understand academic performance using study hours, attendance, assignment marks, midterm marks, and final marks.

## 🎯 Objectives

- Analyze student academic performance
- Calculate important statistical measures
- Identify high, medium, and low performers
- Visualize relationships between different variables
- Analyze correlations between study hours, attendance, and final marks
- Generate simple performance recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 📊 Analysis Performed

1. Dataset creation
2. Data inspection
3. Missing-value analysis
4. Statistical analysis
5. Performance categorization
6. Top student identification
7. Data visualization
8. Correlation analysis
9. Student performance recommendations

## 📈 Key Results

- Average Study Hours: **4.4 hours/day**
- Average Attendance: **84.6%**
- Average Final Marks: **79**
- Highest Final Marks: **97**
- Lowest Final Marks: **48**
- High Performers: **5**
- Medium Performers: **3**
- Low Performers: **2**

### Correlation Results

- Study Hours vs Final Marks: **0.956**
- Attendance vs Final Marks: **0.979**

The sample dataset shows strong positive relationships between study hours, attendance, and final marks. However, correlation does not establish causation.

## ⚠️ Dataset Note

This project uses a sample dataset created for educational and demonstration purposes. It does not represent real institutional student data.
